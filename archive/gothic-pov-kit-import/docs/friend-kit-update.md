# Kit extension: The Friend Who Never Knocks

This project preserves the original Gothic POV Kit and adds one reusable art module, src/kit/art/FriendProps.tsx:

- VisitorShoes: deterministic threshold shoes, warm/cold rim lighting and authored step progress.
- BedsideLamp: deterministic bedside lamp, local glow, pull-chain and controlled on/off light level.
- HeldArm: articulated narrator hand/arm and an optional contact-locked captor layer. Omit captor for a vampire mirror reflection while preserving narrator articulation.

The kit barrel exports the additions. Catalog.tsx adds one panel; docs/kit-catalog.png has been re-rendered to include it. Original fixed style components are unchanged. The original docs/SKILL.md full-source reference predates this addition; use the actual source files and this note for the extension.

See FRIEND-README.md for the new film's render and narration workflow.
