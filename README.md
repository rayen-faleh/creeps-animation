# Gothic POV Kit

Reusable Remotion kit for first-person gothic horror shorts (9:16, 1080×1920, 30 fps): code-drawn sets,
an articulated hand rig, props, film finishing, captions, title card, a synthesised sound engine and a pinned
Kokoro narrator. The full style rules live in the `gothic-pov-style` skill; this README is the quick start.

## Setup

    npm ci
    pip install kokoro-onnx==0.6.1 soundfile numpy scipy
    # model files into voice/ (see voice/README.md); ffmpeg + ffprobe on PATH
    # optional, if Remotion cannot download Chrome: export REMOTION_BROWSER=/path/to/chrome-headless-shell
    npx tsc -p .
    npx remotion studio src/index.ts         # browse TheCount01, Template, Catalog

## Layout

    src/kit/            shared, story-agnostic (never restyle per story; extend it)
      art/              Window, Door, Hand, Room, Props
      sets/             WindowWall, DoorWall
      series/           StoryFrame (grade, grain, captions, audio), Captions, TitleCard, fonts
      fx.tsx util.ts theme.ts index.ts
    src/episodes/<slug>/  one folder per story: brief.md script.json timing.json shots.json
                          Main.tsx scenes/*.tsx cues.py qa.md
    src/catalog/        a panel per kit component -> docs/kit-catalog.png
    src/Root.tsx        registers each story's composition
    public/fonts public/tex public/episodes/<slug>/mix.wav
    scripts/            narrate.py build_audio.py sound_lib.py stills.mjs contact.sh catalog.sh make_grain.py
    work/<slug>/        narration takes (keep them: the final mix alone cannot be re-edited)
    voice/              Kokoro model files (download)

## New story

    cp -r src/episodes/_template src/episodes/my-story
    # edit brief.md, script.json, META in Main.tsx
    python3 scripts/narrate.py src/episodes/my-story
    # shots.json, scenes, sceneAt/gradeAt/dipAt; add to STORIES in src/Root.tsx; cues.py
    python3 scripts/build_audio.py my-story
    node scripts/stills.mjs MyStory 1 5 9 ...
    npx remotion render src/index.ts MyStory out/my-story.mp4 --codec=h264 --crf=18 --x264-preset=veryfast --audio-codec=aac --audio-bitrate=192k

## Stories included

- `the-count-01`: The Count, Part I (64 s), the reference film.
- `_template`: The Knock (18.5 s), the starting point for new stories.
