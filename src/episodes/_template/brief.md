# The Knock — template story brief

| Field | Value |
| --- | --- |
| Folklore rule | Never answer a knock at midnight; something knocks three times |
| Hook | "Every night at midnight, something knocks on my bedroom door." |
| Ritual / who taught it | Mother: "never answer it" (memory, candle grade) |
| Rule broken | He reaches for the ring pull on the fourth night it changes |
| Twist | The knocking at the door was never the threat; the fourth knock comes from the window behind him |
| Clue 1 (spoken) | "Three times. Never more." |
| Clue 2 (visual) | Cold light under the door is moonlight, not a lamp: someone has opened a window in the next room |
| Cliffhanger | A grey hand on the outside of the glass; cut on the push-in |
| Whisper | "Don't turn around." |
| Runtime | 18.5 s (template length; real stories run 60–65 s) |
