# Kit extension — Anytime

- `src/kit/art/ClaspedWrist.tsx`: new contact-locked grasp, with unequal tapered fingers, angled knuckles, opposing thumb, and a shared foreground/reflection pose. Props match HeldArm. Setting captor=false reveals only the narrator arm.

- Catalog adds the organic grasp model panel (18 total), and `docs/kit-catalog.png` is regenerated.
- Fixed series typography, grade, light palette, grain and title design remain inherited from the supplied kit.
