# Rabenfels kit extension

New Townsfolk.tsx supplies original profile residents, articulated arms, cups and coins. New RabenfelsTown.tsx supplies reusable town staging and sparse atmospheric animation over generated flat architectural plates. Four residents are supported: Marta, Matthias, Otto, Grete. Two new panels extend the catalog to twenty panels.

The user expressly requested generated background assets where practical, then rejected realistic rendering and requested a flat cozy Gothic match. Final background prompts and provenance are recorded in the episode. Existing kit finishing components and prior story source remain available.

The final exterior refinement uses two actual frames from the previous Anytime video to guide muted lighting and lightly rugged buildings. Reference frames are included under public/episodes/rabenfels-01/reference/. Final prompts are in final-background-prompts.json.
